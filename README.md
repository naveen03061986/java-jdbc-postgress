# JDBC Postgres CLI

This is a minimal standalone Maven project demonstrating JDBC operations (create, edit, delete, list) against PostgreSQL via a simple command-line UI.

Setup
- Edit `src/main/resources/db.properties` and set `db.url`, `db.user`, and `db.password` to point to your Postgres instance.

Run (using Maven exec plugin)

```bash
mvn -q -Dexec.mainClass="com.example.jdbc.Main" org.codehaus.mojo:exec-maven-plugin:3.1.0:java
```

Alternatively build and run from an IDE.

Notes
- The `users` table is created automatically if it does not exist. `userid` is a serial primary key generated by Postgres.
